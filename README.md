# five-minutes-gungeon

An unofficial fan-made Go adaptation of the board game Five Minute Dungeon.

This is my first larger project written in Go, created as a hands-on way to learn the language while building something significant. Along the way, I used the project to explore idiomatic Go, software design, testing practices, and best practices for structuring and maintaining a non-trivial codebase.

I also took the opportunity to experiment with AI-assisted development, particularly using an AI coding agent to help design and write tests, explore different testing strategies, and discover idiomatic approaches to Go. The project therefore serves both as a playable implementation and as a learning ground for modern development workflows.
